# Gulated

Gulated is an idea for one small TS library that does the job of Commander and Inquirer together: it reads command-line flags and asks interactive questions, with a smooth and fast design. We build everything ourselves, without using the real Commander or Inquirer, and we plan to add some extra ideas of our own.

## 🚧 **Under construction** 
Gulated is **not a library yet**. For now it is only a blueprint, and everything can change.

## Built-with 

- bun v1.4.4. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
- TypeScript (TS).
